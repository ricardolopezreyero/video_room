API de Video Room

Somos un servicio, no una marca. Tu sala de video con cobro por hora se puede leer, escuchar y mostrar desde cualquier otra plataforma — en cinco minutos y sin pedirnos permiso.

1 · Botón «En vivo» para tu sitio (sin llave)

Una línea. Pinta un botón que dice si la sala está en vivo y cuánta gente hay, y lleva a la sala. Se actualiza solo cada 30 segundos.

<script src="https://video.capitaltorreon.com/embed.js" data-room="tu-sala"></script>

Opcionales: data-theme="light" para fondos claros, data-label="Texto cuando no estás en vivo". Funciona en WordPress, Webflow, Notion (bloque embed), Carrd y cualquier HTML.

Si prefieres pintarlo tú, el estado de cualquier sala es público:

curl https://video.capitaltorreon.com/api/v1/public/rooms/tu-sala

  "price_per_hour_cents": 2000, "currency": "MXN" }

2 · Llaves de API

Crea una llave en tu monedero → Integraciones. Se enseña una sola vez. Mándala en cada petición:

Authorization: Bearer vr_live_…

Una llave da acceso a tu cuenta: tu sala, tus números, tus transacciones. Si se te filtra, revócala desde el monedero y crea otra; la vieja deja de funcionar al instante.

3 · Endpoints

Base: https://video.capitaltorreon.com. Todo responde JSON y acepta CORS desde cualquier origen. Los montos van en centavos de peso (2000 = $20 MXN).

RutaQué devuelve
GET/api/v1/meTu cuenta: nombre, foto, saldo, balance de creador, si ya puedes retirar, y tu sala.
GET/api/v1/roomTu sala: en vivo o no, cuánta gente ahora, desde cuándo, cuántas personas esperan tu aviso.
POST/api/v1/room/notify-startingAvisa «empiezo en X minutos» a quienes te siguen (y te manda copia). Cuerpo: {"minutes": 30}.
GET/api/v1/stats?range=7dLo ganado, entradas, espectadores únicos, propinas, mayores donadores y campañas (UTM). range: today, 7d, 30d, all.
GET/api/v1/transactions?limit=50&before=…Tu historial completo de dinero, del más reciente al más viejo. Pagina con next_before.
GET/api/v1/sessions?limit=20Tus transmisiones: duración, entradas, espectadores únicos, propinas y lo que ganaste en cada una.
GET/api/v1/followersCuántas personas activaron «Avísame cuando abra».
GET/api/v1/public/rooms/:slugEstado público de cualquier sala. No necesita llave.

Errores

401 {"error":"unauthorized"} llave ausente, revocada o mal escrita · 404 {"error":"no_room"} · 400 con error y hint cuando el cuerpo no es válido.

Verificar la firma

Al crear el webhook recibes un secret (whsec_…) una sola vez. La firma es HMAC-SHA256(secret, t + "." + cuerpoCrudo) en hexadecimal. Rechaza lo que no coincida o tenga más de 5 minutos.

// Node / Cloudflare Workers / Deno
import { createHmac, timingSafeEqual } from "node:crypto";

export function verificar(cuerpoCrudo, firma, secret) {
  const t  = firma.match(/t=(\d+)/)?.[1];
  const v1 = firma.match(/v1=([a-f0-9]+)/)?.[1];
  if (!t || !v1 || Math.abs(Date.now() / 1000 - Number(t)) > 300) return false;
  const esperada = createHmac("sha256", secret).update(`${t}.${cuerpoCrudo}`).digest("hex");
  return esperada.length === v1.length && timingSafeEqual(Buffer.from(esperada), Buffer.from(v1));
}
# PHP (WordPress)
$firma = $_SERVER['HTTP_X_VIDEOROOM_SIGNATURE'];
preg_match('/t=(\d+)/', $firma, $t); preg_match('/v1=([a-f0-9]+)/', $firma, $v1);
$cuerpo = file_get_contents('php://input');
$ok = hash_equals(hash_hmac('sha256', $t[1] . '.' . $cuerpo, $secret), $v1[1]);

Responde 2xx en menos de 6 segundos. Si tu servidor falla, lo anotamos junto al webhook en tu monedero (último estado y error) para que lo veas sin buscar logs.

Gestionar webhooks por API

GET    /api/v1/webhooks                     # lista + eventos disponibles
POST   /api/v1/webhooks  {"url":"https://…","events":["tip.received","room.live"]}   # devuelve el secret (una vez)
POST   /api/v1/webhooks/:id/test            # manda un ping y te dice cómo respondió tu servidor
DELETE /api/v1/webhooks/:id

5 · Recetas

Zapier / Make / n8n

Crea un «Webhook trigger» (Catch Hook), pega esa URL como webhook aquí, elige los eventos. Cada propina o entrada puede abrir una fila en Google Sheets, un mensaje en Slack o un contacto en tu CRM.

Tu CRM (GoHighLevel, HubSpot…)

Escucha viewer.entered y tip.received: ahí tienes nombre y monto de quien te paga. Son tus mejores leads, ya calificados con dinero.

Tu sitio o tu bio

El botón embebible de arriba. Cuando transmitas, se pone rojo solo.

Tu propio tablero

/api/v1/stats + /api/v1/sessions cada hora, y tienes tus números donde ya ves los demás.

¿Falta algo que necesitas? Escríbenos a hola@capitaltorreon.com con lo que quieres conectar. La API crece con lo que la gente de verdad usa.
